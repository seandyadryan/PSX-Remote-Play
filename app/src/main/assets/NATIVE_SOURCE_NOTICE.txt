Native protocol provider and corresponding source

This application includes Chiaki-ng v1.6.5 (commit
ca5379f4504af6e63cf5d32b5626de2425b2382e), licensed under GNU AGPL version 3
with the upstream OpenSSL linking exception. The provider is independently
built from public source; no code, libraries or assets are extracted from PXPlay.

Original project source files retain their existing MIT license. A combined
application distributing the Chiaki library must satisfy the AGPL conditions,
including providing the complete corresponding application and build source
under AGPL-compatible terms. This notice does not replace those obligations.

This checkout includes the original JNI adapter, CMake build configuration,
generated protocol definitions, and scripts/bootstrap-native.ps1. The complete
upstream source archives and their SHA-256 checksums are pinned in
app/src/main/cpp/dependencies.json. Run that script to retrieve the exact source
archives into app/build/native-provider, then build with gradlew.bat assembleDebug.
Retain and supply those archives with the full checkout when distributing APKs.
No public download URL for this project's complete corresponding source has
been configured by this local development build.
